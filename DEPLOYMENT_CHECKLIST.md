# Deployment Checklist

## Before upload

- [ ] Keep the original Vite project as a backup.
- [ ] Confirm all company claims, team names, office details and project descriptions.
- [ ] Decide whether the contact form should remain `mailto:` or use an email API.
- [ ] Create a company-owned GitHub repository.

## Staging

- [ ] Deploy to Vercel or another Next.js-compatible Node host.
- [ ] Use a temporary URL or `staging.globaluntoldstory.com`.
- [ ] Test desktop, tablet and mobile layouts.
- [ ] Test every internal and external link.
- [ ] Test all 13 services, 12 projects and 5 articles.
- [ ] Check social preview cards.
- [ ] Verify sitemap and robots URLs.
- [ ] Confirm the 404 page.

## Domain launch

- [ ] Back up the current website and database.
- [ ] Prepare 301 redirects from every old URL.
- [ ] Add the custom domain in the hosting dashboard.
- [ ] Apply the DNS records supplied by the hosting provider.
- [ ] Verify SSL.
- [ ] Submit the sitemap in Google Search Console.
- [ ] Monitor forms, analytics and error logs after launch.
